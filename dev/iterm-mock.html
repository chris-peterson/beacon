  1. Tab — the project, with the task indented under it, tinted by the status traffic-light color. Line 1 is also the single-line OS window title, so a window you /rename keeps its project context in Mission Control and the window switcher.
  2. ↖ web button — opens this session's web view: the PR/MR/issue it resolves to, else the repo. Both buttons take their text and their command from statusbar.buttons in your config.
  3. Project chip — the project's name. Needs no git repo, no remote, and no Claude session, so it reads the same in every pane.
  4. Branch — colored by git sync state: green synced, amber ahead/behind, gray no upstream.
  5. ↗ code button — opens this session's working directory in your editor (code by default).
