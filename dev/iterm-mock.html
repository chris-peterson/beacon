  1. Window title — Claude Code's, not beacon's. beacon never paints the title, terminal colors, or cursor.
  2. ↖ web button — opens the URL resolved for this session: an open PR/MR/issue when one matches the branch, else the branch or repo page.
  3. Project chip — the forge identity, abbreviated (gh:, gl:). Appends #42 / !17 when the session is on a deliverable.
  4. Branch — colored by git sync state: green synced, amber ahead/behind, gray no upstream.
  5. ↗ code button — opens this session's working directory in VS Code.
  6. Badge — project name (and task), in the status traffic-light color. The one surface big enough to read in Mission Control.
